# Security Policy

## Supported versions

Only the latest release / `master` is supported. Older versions may not receive fixes.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: **Security → Report a vulnerability**.

Do not open a public issue for a vulnerability. Include:

- affected version or commit;
- reproduction steps;
- impact;
- any suggested fix.

Do not include real credentials, private repository data, or personal information. Replace them with placeholders.

## Scope

Especially relevant:

- GitHub token storage and transport;
- path containment and file operations;
- launch command execution;
- download and update integrity;
- dependency supply chain.
